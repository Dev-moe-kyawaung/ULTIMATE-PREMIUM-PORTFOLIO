## 🚀 **DEPLOYMENT GUIDE**

```bash
# 1. Clone and setup
git clone https://github.com/Dev-moe-kyawaung/portfolio-ultimate.git
cd portfolio-ultimate

# 2. Install dependencies
npm install

# 3. Create environment variables
echo "NEXT_PUBLIC_GITHUB_TOKEN=YOUR_GITHUB_TOKEN" > .env.local

# 4. Test locally
npm run dev
# Open http://localhost:3000

# 5. Deploy to GitHub Pages
npm run deploy
```
